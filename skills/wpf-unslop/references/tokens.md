# 토큰

각 pass의 시작 값입니다. 프로젝트에 이미 좋은 체계가 있으면 그 값을 유지하고 쓰임새만 고칩니다. 이 값은 고정된 스타일이 아니라 출발점이므로 방향에 따라 조정합니다. 바로 쓸 수 있는 XAML 사전은 `assets/Theme.Graphite.Dark.xaml`에 있습니다.

WPF의 길이 단위는 DIP(1/96인치)입니다. 아래 px 값은 모두 DIP로 그대로 씁니다.

## 여백 척도

4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96

| 쓰임 | 값 |
| --- | --- |
| 컨트롤 안쪽 | 4~12 |
| 관련 항목 사이(목록의 행) | 2~8 |
| 그룹 사이(라벨과 목록, 카드 둘) | 12~24 |
| 섹션 사이 | 32~64 |
| 행 높이 | 촘촘 32, 기본 36, 터치 40~44 |
| 창 가장자리 | 일반 창 24~32, 작은 위젯 16~20 |

반복해서 쓰는 여백(카드 `Padding`, 창 가장자리)만 `Thickness` 토큰으로 만들고, 나머지는 척도의 값을 직접 씁니다. 모든 조합을 토큰으로 만들면 오히려 읽기 어렵습니다.

## 앱 레이아웃

- 사이드바 240~280, 내용은 유동 폭, 내용 안쪽 여백 24~32입니다.
- 상단 바나 페이지 머리글 높이는 48~56입니다. 직접 그린 제목 표시줄은 32~40입니다.
- 내비게이션 행 32~36, 행 사이 2~4, 섹션 라벨 위 24 아래 8입니다.
- 한 줄의 통계 카드는 높이가 같고, 대개 한 줄에 작은 카드 3~4개, 숫자만 둡니다.
- 주 차트는 내용 폭의 2/3 이상, 높이 280~360입니다. 옆의 두 번째 데이터 블록은 다른 차트가 아니라 더 좁은 목록이나 표입니다.

## 무채색 단계

앱과 대시보드는 모든 표면에 graphite나 그만큼 회색인 단계를 씁니다. 색조가 필요하면 방향의 세계에 맞는 단계를 고릅니다. warm은 종이, 나무, 음식, 공예, 사람과 관련된 것에, ink는 밤, 하늘, 물, 기술적인 것에 어울립니다. 직접 만들 때는 채도를 아주 낮게 유지해서 표면이 색으로 읽히지 않게 합니다.

XAML 색은 `#AARRGGBB`입니다. hairline은 primary 텍스트 색을 8% 불투명도로 쓰므로 알파 `14`(0x14 = 20/255 ≈ 8%)를 앞에 붙입니다. 6%는 `0F`, 10%는 `1A`입니다.

### 어두운 테마

| 역할 | Graphite | Warm | Ink |
| --- | --- | --- | --- |
| 가장 깊은 표면(사이드바) | `#0F0F10` | `#12110F` | `#07080D` |
| 창 배경 | `#141415` | `#161513` | `#0B0D14` |
| 카드 | `#19191B` | `#1C1A18` | `#11141C` |
| 올라온 표면(활성 행, 입력 상자) | `#232325` | `#262421` | `#1A1E28` |
| Hairline | `#14EDEDED` | `#14EFE9DE` | `#14EEF0F5` |
| Primary 텍스트 | `#EDEDED` | `#EFE9DE` | `#EEF0F5` |
| Secondary 텍스트 | `#A1A1A6` | `#AAA398` | `#A3A9B8` |
| Muted 텍스트와 아이콘 | `#85858B` | `#8A847A` | `#7A8296` |

### 밝은 테마

| 역할 | Graphite | Warm | Ink |
| --- | --- | --- | --- |
| 창 배경 | `#FAFAFA` | `#F7F4EE` | `#F5F7FA` |
| 카드 | `#FFFFFF` | `#FDFBF7` | `#FFFFFF` |
| 올라온 표면(활성 행, 입력 상자) | `#F4F4F5` | `#EFE9DF` | `#ECEFF4` |
| Hairline | `#14171717` | `#141F1B16` | `#14111827` |
| Primary 텍스트 | `#171717` | `#1F1B16` | `#111827` |
| Secondary 텍스트 | `#525252` | `#5E554A` | `#4B5565` |
| Muted 텍스트와 아이콘 | `#737373` | `#7B7266` | `#6B7487` |

Muted 텍스트는 메타 정보와 캡션에만 쓰고, 표면 위에서 대비 4.5:1 근처를 유지합니다. 본문은 primary나 secondary를 씁니다.

의미 색은 어느 단계에도 맞게 톤을 낮춘 값을 씁니다. 긍정은 어두운 테마 `#4CC38A`, 밝은 테마 `#16A34A`입니다. 부정은 어두운 테마 `#E5484D`, 밝은 테마 `#DC2626`입니다.

## 강조색

- 진짜 브랜드 색은 유지합니다. 보라-파랑처럼 색상에서 색상으로 가는 glow gradient는 사용자가 브랜드라고 하지 않는 한 브랜드 색이 아니라 AI 티입니다.
- 브랜드 색이 없으면 세계에서 가져옵니다. 따뜻한 세계에는 amber, coral, ember orange가, 차가운 세계에는 cobalt, teal, 맑은 하늘색이, 자연의 세계에는 moss, sage가 어울립니다. 브랜드가 정말 보라색이 아니면 보라-파랑 계열은 피합니다.
- 강조색 위의 텍스트는 대비 4.5:1 이상입니다. 부족하면 강조색을 어둡게 하거나 어두운 텍스트를 씁니다.
- 강조색은 화면의 몇 퍼센트만 덮습니다. 주요 동작, 선택 상태, 핵심 숫자 하나입니다.

## 버튼

- 주요 동작 버튼 높이 32~36, 대화상자 버튼 32, 툴바 아이콘 버튼 28~32입니다. 좌우 `Padding`은 12~16입니다.
- 어두운 테마의 primary: 단계의 off-white 채움에 어두운 텍스트, 또는 강조색. 밝은 테마의 primary: primary 텍스트 색 채움에 흰 텍스트, 또는 강조색.
- Secondary: 올라온 표면에 hairline, primary 텍스트.
- Ghost(툴바, 목록 안 동작): 평소 투명, hover에서 올라온 표면.
- 어두운 버튼에 위쪽 1px 하이라이트(`#1FFFFFFF`)를 두면 glow 없이 깊이가 생깁니다. 방법은 `xaml.md`의 "깊이와 그림자"에 있습니다.

## 글꼴

방향의 캐릭터로 고릅니다. 아래는 모두 무료이고, 한글이 들어가는 화면은 한글 글꼴을 먼저 정합니다.

| 캐릭터 | 한글 포함 인터페이스 | 영문 위주 인터페이스 | 숫자·메타용 mono |
| --- | --- | --- | --- |
| 정확함, 기술적, 차분함 | Pretendard, IBM Plex Sans KR | Inter, IBM Plex Sans, Segoe UI | JetBrains Mono, IBM Plex Mono, Cascadia Mono |
| 따뜻함, 친근함, 사람 | SUIT, Pretendard | DM Sans, Figtree | IBM Plex Mono |
| 편집, 문학, 공예 | 인터페이스는 Pretendard, 큰 제목만 Noto Serif KR | Inter, 큰 제목만 Newsreader | IBM Plex Mono |
| 장난스러움, 대담함 | SUIT, Gmarket Sans(제목만) | Space Grotesk | JetBrains Mono |

- 시스템 글꼴만 쓸 수 있으면 한글은 `맑은 고딕`(`Malgun Gothic`), 영문은 `Segoe UI`, mono는 `Cascadia Mono, Consolas`입니다. `Segoe UI Variable`은 Windows 11에만 있으므로 단독으로 지정하지 않습니다.
- WPF의 `FontFamily`는 쉼표로 대체 글꼴을 이어 쓸 수 있습니다. 예: `FontFamily="Segoe UI, Malgun Gothic"`. 영문은 Segoe UI, 한글은 맑은 고딕으로 그려집니다.
- serif 제목 글꼴은 큰 제목에만 쓰고 라벨과 버튼에는 쓰지 않습니다.
- 글꼴 파일을 포함하는 방법은 `xaml.md`의 "글꼴 포함"에 있습니다.

## 글꼴 척도

| 쓰임 | 크기 | `LineHeight` | 굵기 |
| --- | --- | --- | --- |
| 작은 라벨, 메타, 개수 | 12 | 16 | Normal, mono 권장 |
| 보조 텍스트, 캡션 | 12~13 | 18~20 | Normal |
| 본문, 내비게이션 항목 | 14 | 20~22 | Normal~Medium |
| 로고 워드마크 | 15~16 | 20 | Medium~SemiBold |
| 섹션 제목 | 16~18 | 24 | Medium |
| 카드 숫자 | 24~32 | 크기와 같음 | Medium, 고정폭 숫자 |
| 페이지 제목 | 24~28 | 크기 × 1.2 | Normal~Medium |

- 한국어 본문은 영어보다 줄 간격을 조금 넉넉하게 잡습니다. 본문 `LineHeight`는 크기의 1.5배 전후입니다.
- `LineHeight`를 쓰려면 `LineStackingStrategy="BlockLineHeight"`를 함께 지정해야 의도한 간격이 나옵니다.
- WPF `TextBlock`에는 자간 속성이 없습니다. 자간이 필요한 디자인은 피합니다.
- 12 미만 크기는 쓰지 않습니다. Windows의 ClearType 렌더링에서 한글이 뭉개집니다.

## 반경

| 요소 | `CornerRadius` |
| --- | --- |
| 키캡, 태그, 작은 버튼 | 4~6 |
| 행, 입력 상자, 버튼 | 6~8 |
| 카드 | 10~12 |
| 패널, 창 | 12~16 |

데스크톱 앱은 웹보다 반경이 조금 작은 편이 자연스럽습니다. Windows 11의 창 모서리 반경은 8입니다.

중첩 반경: 안쪽 = 바깥 − `Padding`, 4 미만 금지. 반경 12인 카드에 `Padding` 8이면 안쪽 항목의 반경은 4입니다.

## 깊이

- 어두운 테마: 표면 단계와 hairline. 활성 행이나 버튼 위쪽에 1px 하이라이트 `#1FFFFFFF`.
- 밝은 테마: 작은 것은 `BlurRadius="4" ShadowDepth="1" Opacity="0.06"`, 떠 있는 것(팝업, 메뉴)은 `BlurRadius="24" ShadowDepth="8" Opacity="0.08"`, 색은 검정. 텍스트를 담은 요소에 직접 걸지 않습니다(`xaml.md` 참고).

## 움직임

easing 곡선은 하나만 씁니다. 원본 unslop의 `cubic-bezier(0.22, 1, 0.36, 1)`은 ease-out quint와 같으므로 WPF에서는 `QuinticEase`에 `EasingMode="EaseOut"`을 씁니다.

| 쓰임 | 길이 |
| --- | --- |
| hover, press, 토글 | 0:0:0.12 ~ 0:0:0.18 |
| 메뉴, 팝업, tooltip | 0:0:0.16 ~ 0:0:0.22 |
| 등장, 시트, 레이아웃 변화 | 0:0:0.30 ~ 0:0:0.50 |
| 항목 사이 stagger | 40~60ms, 최대 6개 |

- 등장할 때 떠오르는 거리: 6~12. press 축소: 0.97~0.98.
- `Opacity`, `RenderTransform`, brush 색만 animate합니다.
